# Справочник Kotlin и Android (RU / UZ)

Откройте `index.html` в браузере — сервер не нужен.
Qo‘llanmani ochish uchun `index.html` faylini brauzerda oching.

## Структура
- `index.html` — разметка
- `css/style.css` — оформление (тёмная и светлая темы, телефон и компьютер)
- `js/i18n.js` — **тексты интерфейса** на русском и узбекском
- `js/data.js` — **всё содержимое справочника**: 150 понятий на двух языках
- `js/app.js` — логика: поиск, прогресс, карточки, викторина, песочница

## Как устроено
- Язык переключается кнопками RU / UZ в шапке; выбор запоминается. По умолчанию берётся язык браузера.
- 96 примеров Kotlin (разделы «Ключевые слова», «Типы», «Коллекции», «Функции», «Корутины») были скомпилированы и выполнены настоящим Kotlin 2.0.21. Вывод в кнопке «Показать вывод» — это реальный результат запуска.
- Примеры Android и Compose (53 шт.) нельзя выполнить на сайте: им нужен Android SDK. Их синтаксис проверен компилятором Kotlin, XML проверен на корректность.
- Кнопка «Запустить онлайн» и «Песочница» используют официальный виджет Kotlin Playground (JetBrains, `unpkg.com/kotlin-playground`). Нужен интернет, а код при запуске отправляется на серверы JetBrains.
- Прогресс (выученные понятия, интервалы повторения) хранится в localStorage браузера на этом устройстве.

## Как добавить своё понятие
В `js/data.js` в нужный раздел допишите строку в `items`:

    ["имя", "описание RU", "описание UZ", "код", "«Важно» RU", "«Важно» UZ", уровень, { опции }]

Уровень: 1 — основы, 2 — дальше, 3 — продвинутое.
Опции: `run: true` (показать кнопку «Запустить онлайн»), `out: "вывод программы"` (покажется по кнопке «Показать вывод»), `lang: "xml"` или `"bash"` (подсветка), `noRun: true` (запуск отключён).
Если пишете `out` — получите его реальным запуском, а не «из головы»: тогда он попадёт и в викторину «что выведет программа».
В тексте `код` выделяется обратными кавычками.

## Как добавить язык
Скопируйте блок `ru` в `js/i18n.js`, переведите значения, затем допишите перевод во все записи `data.js` и добавьте код языка в `LANGS` (`app.js`) и кнопку в `index.html`.


## Счётчик устройств / Qurilmalar hisoblagichi
Сверху сайта показывается число устройств, которые заходили. Одно устройство (браузер) считается один раз — повторные заходы счётчик не увеличивают. Устройство опознаётся по случайному id в localStorage и cookie; если очистить данные браузера или открыть сайт в режиме инкогнито, оно посчитается заново.

- Нужен сервер: `npm start` (или `node server.js`), порт берётся из `PORT`. Без сервера (открытие `index.html` файлом, статический хостинг) счётчик скрыт.
- Данные лежат в `DATA_DIR/visitors.json` (по умолчанию `./data`). Хранятся только SHA-256-хэши id.
- **Railway:** диск без Volume стирается при каждом деплое — тогда счётчик обнулится. Создайте Volume, смонтируйте его (например, в `/data`) и задайте переменную `DATA_DIR=/data`.
- Защита от накрутки: не больше 20 новых устройств в час с одного IP.


## Языки и содержимое / Tillar / Languages
Интерфейс и все 150 понятий доступны на русском (RU), узбекском (UZ) и английском (EN). Язык выбирается кнопками в шапке и определяется по языку браузера.

- `js/data.js` — исходные понятия (RU и UZ) и примеры кода.
- `js/data_en.js` — английские разделы, дорожная карта, описания и пометки «Важно знать».
- `js/data_more.js` — расширенные сведения по каждому понятию на трёх языках: «Подробнее», «Частая ошибка» и «Связанные понятия» (ссылки на другие записи по имени).
- `js/i18n.js` — тексты интерфейса (блоки `ru`, `uz`, `en`).
